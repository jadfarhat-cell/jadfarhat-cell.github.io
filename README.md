# Jad Farhat — Applied AI Portfolio

This repository hosts my public portfolio at **jadfarhat-cell.github.io**.

I am a Software Engineering student in Montréal building applied AI systems across retrieval-augmented generation, computer vision, and full-stack development.

## Featured projects

### [Document Assistant](https://github.com/jadfarhat-cell/document-assistant)
Local RAG application supporting PDF, DOCX, Markdown, source-code, and text ingestion. Built with Python, Ollama, ChromaDB, sentence-transformer embeddings, FastAPI, Gradio, and a CLI.

### [Face Swap App](https://github.com/jadfarhat-cell/face-swap-app)
FastAPI computer-vision pipeline using InsightFace, OpenCV, ONNX models, and FFmpeg to process video while retaining the original audio stream.

### [MeetingMind](https://github.com/jadfarhat-cell/meetingmind)
Electron and React meeting-assistant prototype integrating speech transcription and LLM-generated summaries, action items, and follow-up drafts.
